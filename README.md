## What is ESP32?

ESP32 is a powerful low-cost microcontroller used for:

* IoT
* Robotics
* AI sensors
* Wireless systems
* Smart automation

It has:

* Built-in Wi-Fi
* Bluetooth
* Dual-core processor
* GPIO pins
* ADC/DAC
* PWM support
